# Interface fonts

- Fraunces v38, upright variable WOFF2 with optical size 9–144 and weight 400–700.
  [Google Fonts source and license](https://github.com/google/fonts/tree/main/ofl/fraunces)
- Source Sans 3 v20, upright and italic variable WOFF2.
  [Google Fonts source and license](https://github.com/google/fonts/tree/main/ofl/sourcesans3)

The Latin and Latin Extended subsets are the WOFF2 files served by the Google
Fonts CSS API for these families. They are hosted locally with their respective
SIL Open Font License 1.1 notices. See `apps/web/src/fonts.css` for the weight and
Unicode ranges.
