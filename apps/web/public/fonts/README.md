# Interface fonts

- Fraunces v38, upright variable WOFF2 with optical size 9–144 and weight 400–700.
  [Google Fonts source and license](https://github.com/google/fonts/tree/main/ofl/fraunces)

The Latin and Latin Extended subsets are the WOFF2 files served by the Google
Fonts CSS API for Fraunces. They are hosted locally with its
SIL Open Font License 1.1 notice. See `apps/web/src/fonts.css` for the weight and
Unicode ranges.
