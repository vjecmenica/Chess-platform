# Chessnut chess pieces

The 12 SVG pieces in this directory are the **Chessnut** set by **Alexis Luengas**, obtained from [Lichess's Chessnut asset directory](https://github.com/lichess-org/lila/tree/master/public/piece/chessnut). Lichess's [asset credits and license list](https://github.com/lichess-org/lila/blob/master/COPYING.md) identify Chessnut as licensed under the **Apache License 2.0**. The full license text is in [LICENSE-2.0.txt](LICENSE-2.0.txt). The SVGs are bundled without changes.

We chose this set for its clear, traditional silhouettes and license suitable for a public platform. Lichess lists the Alpha set as free for personal, non-commercial use, so Alpha assets are not included here.
